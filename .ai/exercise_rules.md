# Development Learning Rules

The user is learning while building this project.

## Teaching Mode

- Explain architectural reasoning in Spanish.
- Keep code-facing names in English.
- Prefer progressive implementation.
- Do not dump the entire application at once.
- When possible, let the user implement the next small piece after understanding it.
- Point out mistakes clearly before moving forward.
- Use real project context instead of isolated toy exercises.

## Code Assistance

When the user asks for guidance rather than a complete solution:

1. Explain the goal.
2. Explain where the code belongs architecturally.
3. Give the smallest useful hint or skeleton.
4. Let the user attempt it.
5. Review their implementation.

When the user explicitly asks for complete code, complete code may be provided.

## Validation

Before moving to a new milestone, verify the previous milestone works with:

- tests,
- a minimal manual check,
- or both.

Do not hide errors by bypassing architecture rules.
